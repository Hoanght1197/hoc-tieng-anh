# Bé Học Tiếng Anh

App web học từ vựng tiếng Anh cho bé 4 tuổi. Mở `index.html` hoặc bản GitHub Pages, bấm Chia sẻ > Thêm vào màn hình chính trên iPhone để dùng như app.

- `index.html` bản PWA (ảnh trong `img/`, tiếng trong `audio/`)
- `bundle.html` bản 1 file, nhúng sẵn toàn bộ ảnh + tiếng
- `tools/build.py` build lại sau khi sửa `src/`
